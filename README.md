# 🌸 La Peonía — Floristería Boutique

Frontend desarrollado en **React** para La Peonía, una floristería boutique especializada en ramos artesanales y diseño floral para eventos.

El proyecto está enfocado en una experiencia visual elegante, diseño minimalista y una identidad floral cuidada.

---

## ✨ Características

- 🌿 Diseño moderno y minimalista
- 💜 Identidad visual personalizada (`#542f52`)
- 📱 Diseño responsive (desktop, tablet y móvil)
- 🔍 Buscador integrado
- 🧭 Navegación dinámica con enlace activo
- 🎨 Hero section con overlay suave y composición en dos columnas
- 🪄 Micro-interacciones y transiciones suaves

---

## 🛠 Tecnologías utilizadas

- React
- React Router DOM
- CSS puro (sin frameworks)
- Font Awesome
- Google Fonts (Inter)

## 🚀 Instalación y uso

Clona el repositorio:

```bash
git clone https://github.com/tbaldassarrer/la-peonia-frontend.git
```

Entra en la carpeta del proyecto:

```bash
cd la-peonia-frontend
```

Instala las dependencias:

```bash
npm install
```

Ejecuta el proyecto:

```bash
npm start
```

La aplicación se abrirá en:

```
http://localhost:3000
```
